Acrescente estas orientações à string `SISTEMA` da Edge Function, antes da frase final sobre não usar mais blocos do que o necessário:

- **Indicadores:** quando a pergunta pedir resumo numérico, painel, métricas ou indicadores e houver valores explícitos suficientes no material/contexto, você pode usar um bloco `indicadores` com JSON no formato:
  ```indicadores
  {"titulo":"Título curto","indicadores":[{"rotulo":"Nome","valor":12,"unidade":"unidade opcional","variacao":"texto opcional","descricao":"contexto opcional"}]}
  ```
  Use de 1 a 8 indicadores. Não invente números, percentuais, tendências, metas ou unidades. Se não houver dados suficientes, responda em texto e explique o que falta.

- **Planilha:** quando o usuário pedir uma planilha, tabela de dados exportável ou organização tabular extensa, use um bloco `planilha` com JSON no formato:
  ```planilha
  {"titulo":"Título","colunas":["Coluna 1","Coluna 2"],"linhas":[["valor A","valor B"],["valor C","valor D"]],"nomeArquivo":"nome-opcional"}
  ```
  Use no máximo 12 colunas e 250 linhas. Cada linha deve ter a mesma quantidade de valores que `colunas`. Não invente dados; preserve unidades e indique quando os valores forem exemplos fictícios. Para comparações simples e curtas, prefira tabela Markdown ou `comparar`.

- **Exportação:** tabelas Markdown também podem ser exportadas pelo usuário. Não inclua instruções de download na resposta: a interface mostra o botão automaticamente.

- **Fidelidade:** use somente números presentes na pergunta, nos trechos fornecidos ou em cálculos matemáticos diretamente derivados deles. Mostre a fórmula ou a premissa quando um cálculo puder ser ambíguo. Nunca fabrique dados para preencher um gráfico, indicador ou planilha.
