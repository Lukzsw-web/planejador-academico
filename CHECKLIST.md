# Checklist de validação

Depois de enviar os arquivos e atualizar o `index.html`:

- [ ] A aba FarmácIA abre normalmente.
- [ ] As respostas comuns continuam renderizando normalmente.
- [ ] Os blocos `grafico`, `comparar`, `fluxo` e `formula` existentes continuam funcionando.
- [ ] Um bloco `indicadores` válido aparece como cartões.
- [ ] Um bloco `planilha` válido aparece como tabela rolável.
- [ ] O botão **Baixar CSV** baixa um arquivo que abre no Excel/Google Planilhas.
- [ ] Tabelas Markdown comuns também mostram botão de exportação.
- [ ] A interface continua utilizável em tela estreita (celular).
- [ ] Tema claro e escuro permanecem legíveis.

Se a FarmácIA parar de abrir, reverta primeiro as duas inclusões no `index.html`. Não apague nem substitua os arquivos originais.
